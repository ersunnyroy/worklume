# @worklume/mobile

The Worklume mobile app for iOS and Android, built with Expo. It runs as a development build
(`expo-dev-client`), not in Expo Go, because later features (background location, geofencing)
need native modules. Right now it is a scaffold with a single placeholder screen; the shell and
sign-in arrive in E24-S01.

## Layout

| Path               | Holds                                                    |
| ------------------ | -------------------------------------------------------- |
| `index.ts`         | Entry point registering the root component               |
| `src/`             | App code and its Jest tests                              |
| `app.config.ts`    | App identity, bundle IDs, permissions and config plugins |
| `assets/`          | App and adaptive icons                                   |
| `ios/`, `android/` | Generated by `expo prebuild`; never committed            |

## Prerequisites

Node and pnpm as for the rest of the repo. Native builds also need:

- **iOS:** macOS with Xcode 26.4 or later (Expo SDK 57's minimum) and CocoaPods.
- **Android:** Android Studio with the Android SDK, and JDK 17.

## Commands

| Command                                          | Does                                                     |
| ------------------------------------------------ | -------------------------------------------------------- |
| `pnpm --filter @worklume/mobile dev`             | Start Metro for a development build                      |
| `pnpm --filter @worklume/mobile build`           | Export the iOS and Android JavaScript bundles to `dist/` |
| `pnpm --filter @worklume/mobile native:generate` | Generate `ios/` and `android/` from `app.config.ts`      |
| `pnpm --filter @worklume/mobile test`            | Jest with React Native Testing Library                   |

To run on a device or simulator, generate the native projects, then build them with Xcode or
Android Studio (or `pnpm exec expo run:ios` / `expo run:android`).

## CI

`.github/workflows/mobile.yml` lints, typechecks, tests and exports the bundles, then builds a
release APK (signed with the debug key, for testing only) and an unsigned iOS simulator app.
Artifacts are kept for 14 days. Store signing and releases arrive with E24.

## Versions

Expo SDK 57 fixes the versions of React (19.2.3), React Native (0.86.3) and its own modules. The
web app uses a newer React; each app keeps the version its platform supports. Upgrade the SDK with
`pnpm exec expo install --fix` and commit the result.
